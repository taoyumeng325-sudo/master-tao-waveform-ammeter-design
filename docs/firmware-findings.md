# 原版固件逆向记录

输入为 V0.0.60-1107 独立 app 文件及其原包分区表。在 REA 6.10.1 下，该 app 无法按 ESP Flash 归档直接打开。备用流程把 8 个 ESP 镜像段映射到 RV32 分析用 ELF，在 Ghidra 12.0.4 自动分析，再按字符串和数据交叉引用反编译。

| 原地址 | 核对结果 |
|---|---|
| 0x40022DAC | TFT 初始化。引用 TFT.c、GPIO 配置、ST7701 构造及 DSI 日志 |
| 0x4002268E | LVGL 初始化。日志参数对应 LVGL 9.5.0、854×480 逻辑画面、PPA 旋转 270° |
| 0x40022398 | LVGL 刷新回调地址，由初始化函数写入回调槽。计算矩形宽高、将 X 镜像成物理方向、调度刷新 |
| 0x40044586 | LCD 面板 draw_bitmap API，字符串引用和虚函数分发逻辑吻合 |
| 0x400D80D0 | 51 项 ST7701 命令表，32 位命令、数据指针、长度、延时 |

TFT 初始化可确认 PHY LDO 通道 3、2500 mV，屏幕电源 GPIO31 和 GPIO32，复位 GPIO28，背光 GPIO33。DSI 双通道 400 Mbps，DPI 像素时钟 30 MHz。物理面板 480×854，水平同步、后沿、前沿为 6、40、40，垂直为 4、8、10。读取了镜像段中存在的命令 payload，6 个指向未加载 RAM 的 payload 使用零填充作为测试默认值，不能认定为原运行时值。实现使用 ESP-IDF DPI 单帧缓冲和整帧缓存写回，原版使用 PPA/DMA2D 和三个物理帧缓冲。

分区表为 nvs=0x9000/0x6000、phy_init=0xF000/0x1000、factory=0x10000/0x400000。应用无独立 UI 分区。图片加载入口和所有内置图片、字库的尺寸和偏移仍未完整识别。实机 eFuse 保护状态无法根据独立 app 判断。
