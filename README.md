# 陶师傅波形电流表 · ESP32-P4 开发工程

这是 GD-A-004 V2.1 的新版界面测试工程。开机显示合并后的中文仪表首页，随后每五秒自动切换中文数显、指针、曲线和指针＋曲线界面，屏幕标记 DEMO。指针页按读数自动选择 250 mA、2.5 A、5 A、10 A 或 16 A，组合页固定 16 A。曲线保留约 30 秒的模拟读数。电源监测演示后进入独立的万用表中文封面，再依次轮换交流电压、直流电压、二极管和电阻。四档各自记录最近 20 条模拟历史数据，并高亮最后一条。未采集时显示 `--`，前端显式报告开路或超量程时显示 `O.L`。万用表页面的参考量程来自参考图，只显示在模拟模式下。采样、按键和校准驱动尚未接入。

## Windows 重新编译

使用支持 ESP32-P4 的 ESP-IDF 6.0.1，解压到无空格和中文的目录，例如 `C:\esp\tao_ammeter`。打开 ESP-IDF 终端，运行：

```cmd
cd /d C:\esp\tao_ammeter
build.cmd
```

脚本首次设置目标 ESP32-P4，然后编译。应用在 `build\tao_ammeter.bin`，写入地址以 `build\flasher_args.json` 为准。ESP-IDF 构建不依赖 Ghidra 或 REA。

## 更换界面

- 在 `main\ui_theme.h` 改颜色。
- 在 `main\ui.c` 改布局、读数卡、表盘、曲线和万用表历史网格。万用表以 `main\dmm.h` 定义的 V/Ω 读数接口接入数据。中文字形表 `main\ui_glyphs.h` 已随源码提供，可直接编译。新增字形时用 `tools\make_dashboard_font.py` 重新生成。可以换掉整个文件的实现，请保留 `main\ui.h` 中的 `ui_render` 和 `ui_push` 接口。
- 修改后重新运行 `build.cmd`。界面逻辑以 854×480 在 RGB565 缓冲中分条绘制，`main\board.c` 负责转成物理面板的 480×854 方向。

## 真机测试范围

板级显示代码参考原 V0.0.60-1107 的屏幕初始化函数和命令表。命令表中有六项指向镜像未加载的 RAM，本版使用零初值作为测试假设。真机上的下列事项仍待验证：面板命令有效性、屏幕方向和色彩、PSRAM 配置、背光以及刷新表现。此版只适用于匹配的 GD-A-004 V2.1 测试机，不能用于实际测量。

原包的应用最低芯片版本为 ESP32-P4 v3.1，此工程的构建采用同样的最低芯片版本。原固件和本工程均为 16 MB DIO 80 MHz，分区偏移一致。保留原版恢复包，优先在原版引导和分区已经匹配时只更新应用，避免重写设备设定。不执行全片擦除。遇到此前的 `2-sync fail` 时，须先让 Windows 烧录工具与设备下载模式握手。

GUI 和渲染逻辑已在桌面验证。本工程使用 ESP-IDF 6.0.1 实际完成交叉编译，尚未接触实体设备。

## 可选的开机图片预览

将原图放进 `ui_images`，用 `01.png`、`02.jpg` 等文件名排序。支持 PNG、JPG、JPEG 和 WebP，最多八张。第一次编译带图版本前，在 ESP-IDF 终端安装 Pillow：

```cmd
python -m pip install Pillow
build.cmd
```

当前交付的中文界面根据聊天参考图绘制。若需要追加原图预览，编译时会把图片转换为带 RGB565 调色板的 854×480 图像，等比缩放并用黑底填充。开机依次展示每张图片三秒，添加 UI PREVIEW 标识，然后进入动态数显、指针和曲线演示。原图上的读数随图片展示，动态读数仍由 UI 代码绘制。
